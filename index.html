How this is counted

Contracts: Ethereum 0xE731dFadBFf20542E10D09D26Fc71445C70d4232, Arbitrum and Base 0x5555Fa783936C260f77385b4E153B9725feF1719. v3 went live on Arbitrum and Base on January 20, 2026 and on Ethereum on May 14, 2026, so earlier days are zero.

Source: poidh's public indexer (indexer.poidh.xyz), which records each contract action with its transaction hash. A day's number is the count of distinct transaction hashes that day (UTC). "By action" groups them as claims (claim created), bounties (created or canceled), funding (ETH added to or taken out of open bounties), voting (sent to vote, votes, results) and accepted claims. Transactions sent through smart wallets count too, so Ethereum can show more than a block explorer's list of direct calls. Plain withdrawals of winnings are not indexed per bounty and are not included.

A GitHub Action rebuilds the data every day at 00:20 UTC and redeploys this page. Code and data: github.com/swiftbotlab/poidh-daily-txs.
