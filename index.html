How this is counted

Contracts: Ethereum 0xE731dFadBFf20542E10D09D26Fc71445C70d4232, Arbitrum and Base 0x5555Fa783936C260f77385b4E153B9725feF1719. The v3 contracts went live on Arbitrum and Base on January 20, 2026 and on Ethereum on May 14, 2026, so earlier days show zero.

Source: poidh's public indexer (indexer.poidh.xyz), which records each contract action with its transaction hash: bounty created or joined, claim created, submitted for vote, voted, vote resolved, claim accepted, bounty canceled. A day's number is the count of distinct transaction hashes that day (UTC). Transactions sent through smart wallets count too, so the Ethereum number can be higher than a block explorer's list of direct calls. Withdrawals are not indexed per bounty and are not included.

A GitHub Action rebuilds the data every day at 00:20 UTC. Code and data: github.com/swiftbotlab/poidh-daily-txs.
